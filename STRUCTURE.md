# Project Structure

This file is the authoritative reference for the project directory layout.
**Agents and scripts must read this file to determine where to read/write files.**

---

## Top-Level Layout

```
Science/
├── STRUCTURE.md          ← this file
├── Changelog.md          ← project changelog (human + agent maintained)
├── IDEAS.md              ← research idea notes
├── .env                  ← API keys (ANTHROPIC_API_KEY, S2_API_KEY, ZOTERO_API_KEY, etc.)
├── setup_env.sh          ← venv setup script
├── settings.json         ← Claude Code settings
│
├── topics/               ← research topic inputs (human-managed)
├── data/                 ← pipeline intermediate files (auto-generated)
├── db/                   ← SQLite database
├── figures/              ← visualization outputs (PNG, generated by scripts/analysis/)
├── outputs/              ← final analysis outputs
├── scripts/              ← all Python scripts
├── schema/               ← JSON schemas
├── notes/                ← design documents and SOPs
├── logs/                 ← runtime logs
├── paper-fetcher-mcp/    ← Node.js browser automation MCP
└── venv/                 ← Python virtual environment (do not modify)
```

## topics/ — Research Topic Inputs

Human-managed. Contains PDFs and paper lists organized by research direction.

```
topics/
├── mta/                          ← Methanol to Aromatics (primary topic)
│   ├── pdfs/                     ← PDF files, named as <sanitized_doi>.pdf
│   ├── shortlists/               ← manually curated paper lists (.md)
│   └── search_queries/           ← saved OpenAlex query configs (.json)
├── co2a/                         ← CO2 to Aromatics (secondary topic)
│   ├── pdfs/
│   ├── shortlists/
│   └── search_queries/
└── shared/                       ← papers relevant to both topics
    └── pdfs/
```

**Rules:**
- PDF filename convention: `<doi_with_slashes_replaced_by_underscores>.pdf`
  - Example: `10.1016_j.apcatb.2021.120073.pdf`
- New PDFs go into the topic-specific `pdfs/` folder
- If a paper spans both MTA and CO2a, place in `topics/shared/pdfs/`

---

## data/ — Pipeline Intermediate Files

Auto-generated by scripts. Numbered folders reflect pipeline stage order.
Each file is named with its source DOI (sanitized) for traceability.

```
data/
├── 00_raw/               ← Stage A: raw text extracted from PDF
│   └── <doi>.txt / <doi>.full.txt
│
├── 01_chunks/            ← Stage B: chunked paragraphs
│   └── <doi>.chunks.jsonl
│
├── 02_enriched/          ← Stage B.5: CDE2-enriched chunks
│   └── <doi>.enriched.jsonl
│
├── 03_evidence/          ← Stage D: LLM-extracted evidence + tables
│   ├── <doi>.llm_evidence.jsonl    ← claim-level evidence records
│   ├── <doi>.high_value_chunks.jsonl
│   ├── <doi>.cde_records.jsonl
│   └── <doi>.tables.jsonl          ← Vision-extracted table records
│
├── 04_search/            ← OpenAlex search results
│   ├── <query>_<date>.csv          ← search output from search_openalex.py
│   ├── papers-v1.jsonl             ← legacy paper metadata
│   └── legacy/                     ← old raw search JSONs (archive)
│
└── 05_normalized/        ← Phase 3: normalized records ready for DB import
    ├── feature_matrix_<date>.csv
    └── feature_matrix_<date>.pkl
```

**Rules:**
- Never write final outputs to `data/` — use `outputs/` instead
- Intermediate files are safe to regenerate; do not hand-edit them
- All JSONL files: one JSON object per line

---

## db/ — SQLite Database

```
db/
└── catalysis.db          ← main database (built in Phase 3)
```

**Schema (Phase 3 target — 4 tables):**
- `papers` — paper-level metadata (doi, title, year, journal, paper_type)
- `catalyst_systems` — one row per catalyst system per paper
  (active_metal, promoter, support, feed_type, conditions)
- `claims` — one row per scientific claim
  (claim_type, subject, predicate, object, evidence_type, confidence)
- `performance_records` — normalized performance metrics
  (catalyst_system_id, metric_name, value, unit, condition_set)

## outputs/ — Analysis Outputs

Results meant for human review or publication. Separated from pipeline
intermediates in `data/`.

```
outputs/
├── viz/                  ← Phase 4: visualizations
│   ├── heatmap_<date>.html         ← active_metal × support performance heatmap
│   ├── pareto_<date>.html          ← Pareto frontier (conversion vs selectivity)
│   ├── gap_heatmap_<date>.html     ← combinatorial gap map
│   ├── shap_beeswarm_<date>.png    ← SHAP feature attribution plot
│   └── screening_scatter_<date>.html ← Phase 5 virtual screening results
│
├── reports/              ← Phase 4-5: structured analysis reports
│   ├── gap_candidates_<date>.csv   ← unexplored catalyst combinations
│   ├── shap_report_<date>.html     ← SHAP analysis report
│   ├── contradiction_report_<date>.csv
│   └── model_eval_<date>.json      ← ML model CV scores
│
├── models/               ← Phase 5: trained ML model files
│   ├── xgb_selectivity_<date>.pkl
│   └── rf_conversion_<date>.pkl
│
└── candidates/           ← Phase 5-6: virtual screening results
    └── top_candidates_<date>.csv   ← ranked candidate list for wet-lab
```

**Rules:**
- All output filenames include `_<date>` suffix (YYYY-MM-DD) for versioning
- Never overwrite; always create new dated file
- `candidates/top_candidates_<date>.csv` is the handoff to wet-lab

## scripts/ — Python Scripts

Organized by pipeline phase.

```
scripts/
├── search/               ← Phase 0: discovery & OA acquisition
│   ├── discover.py                 ← Phase 0 orchestrator (query → ranked candidates)
│   ├── fetch_oa.py                 ← Phase 0 OA-only PDF fetcher
│   ├── fetcher.py                  ← PaperFetcher interface + Candidate dataclass
│   ├── search_openalex.py          ← OpenAlex search + Unpaywall OA check (legacy CSV CLI)
│   ├── semantic_scholar.py         ← Semantic Scholar API wrapper (citations, recommendations)
│   └── s2_abstract_dryrun.py       ← abstract-coverage measurement tool
│
├── extraction/           ← Phase 1-2: PDF → structured evidence
│   ├── chunk_review_pdf.py         ← Stage A: PDF text extraction + chunking
│   ├── select_high_value_chunks.py ← Stage B: chunk scoring (regex)
│   ├── enrich_chunks_cde.py        ← Stage B.5: CDE2 entity enrichment
│   ├── extract_records_cde.py      ← Stage C: structured record extraction
│   ├── extract_llm_evidence.py     ← Stage D: LLM 3-pass claim extraction
│   ├── extract_tables_vision.py    ← Stage D+: Vision table extraction
│   └── models/                     ← custom CDE2 catalysis models
│
├── db/                   ← Phase 3: database construction
│   └── build_db.py                 ← merge JSONL → SQLite (schema + migration)
│
├── analysis/             ← Phase 4: gap detection, visualization
│   ├── visualize_mta_heatmap.py    ← MTA: catalyst × zeolite → aromatic selectivity
│   ├── visualize_co2_heatmap.py    ← CO₂: metal × zeolite/support heatmaps + scatter
│   ├── visualize_co2_conversion.py ← CO₂: 363-pt conversion stripplot/heatmap/histogram
│   ├── visualize_co2_bifunctional.py ← CO₂: hydrogenation × aromatization component heatmap
│   ├── aggregate_extra_fields.py   ← count extra_fields keys for schema promotion
│   ├── filter_ref_chunks.py        ← filter reference-list chunks from evidence
│   ├── extract_ref_lookup_vision.py← Vision OCR for reference list pages
│   └── resolve_refs_openalex.py    ← source_reference → DOI via OpenAlex
│
├── zotero/               ← Zotero library management
│   ├── add_dois_to_zotero.py       ← add papers by DOI (Crossref + Claude classify)
│   ├── upload_pdfs_to_zotero.py    ← upload PDF files to existing Zotero items
│   └── zotero_inbox_triage.py      ← triage inbox items into collections
│
└── ml/                   ← Phase 5: ML model training and screening
    ├── feature_engineering.py      ← DB → feature matrix
    ├── train_model.py              ← XGBoost/RF training
    └── screen_candidates.py        ← virtual screening of new combinations
```

## Pipeline Flow Summary

```
topics/*/pdfs/          ← input PDFs
       ↓  scripts/extraction/chunk_review_pdf.py
data/00_raw/
       ↓  select_high_value_chunks.py + enrich_chunks_cde.py
data/01_chunks/ → data/02_enriched/
       ↓  extract_llm_evidence.py + extract_tables_vision.py
data/03_evidence/
       ↓  scripts/db/normalize_keys.py + build_db.py
db/catalysis.db
       ↓  scripts/analysis/*
outputs/reports/ + outputs/viz/
       ↓  scripts/ml/train_model.py + screen_candidates.py
outputs/models/ + outputs/candidates/top_candidates.csv
       ↓  wet-lab experiment
(feedback loop back to db/)
```

## File Naming Conventions

| Type | Convention | Example |
|------|-----------|---------|
| PDF | `<sanitized_doi>.pdf` | `10.1016_j.apcatb.2021.120073.pdf` |
| JSONL | `<sanitized_doi>.<stage>.jsonl` | `10.1016_j.apcatb.2021.120073.llm_evidence.jsonl` |
| Search CSV | `<sanitized_query>_<YYYY-MM-DD>.csv` | `methanol_to_aromatics_2026-03-20.csv` |
| Output | `<type>_<YYYY-MM-DD>.<ext>` | `gap_candidates_2026-04-01.csv` |
| DB | fixed name | `catalysis.db` |
| Model | `<algo>_<target>_<YYYY-MM-DD>.pkl` | `xgb_selectivity_2026-05-01.pkl` |
