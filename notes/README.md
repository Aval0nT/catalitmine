# science

统一存放 CO2 hydrogenation / higher alcohols 相关科研资料。

## 目录说明

- `pdfs/`：后续下载或整理的文献 PDF
- `data/`：持续更新的 JSONL / CSV 数据文件
- `schema/`：数据库字段模板、筛选规则、样例记录
- `db/`：后续 SQLite 等数据库文件
- `notes/`：检索策略、筛选说明、人工笔记

## 当前约定

- 主题主轴：CO2 hydrogenation
- 重点子方向：higher alcohols / C2+ alcohols / mixed alcohols
- 核心筛选规则见 `schema/screening_rules.json`
- 单篇记录模板见 `schema/paper_record.schema.json`
